# Employee Management System

## 🚀 Project Overview
This is a backend REST API application built using Spring Boot to manage employee data efficiently. It provides CRUD operations and demonstrates backend development skills.

## 🛠️ Tech Stack
- Java
- Spring Boot
- MySQL
- Spring Data JPA

## 📌 Features
- Create Employee
- Get All Employees
- Get Employee by ID
- Delete Employee
- RESTful API design

## 🔗 API Endpoints
- GET /api/employees
- POST /api/employees
- GET /api/employees/{id}
- DELETE /api/employees/{id}

## 🧪 Testing
Tested using Postman
